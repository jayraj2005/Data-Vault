How Edit Access Works
  1. Go to Dataset Selection → Admin Datasets and click Request Edit.
  2. Describe your reason — the admin will review it.
  3. Once Approved, you can open the dataset editor directly from this page or from the Admin Datasets tab.
  4. All your edits are saved back to the file and the admin is notified. Every save is recorded on the blockchain.
  5. The admin can lock a dataset at any time — once locked, you can still view it but can't make further changes until it's unlocked again.
